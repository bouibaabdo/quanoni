# قانوني (Qanoni) — منصة إدارة مكاتب المحاماة في المغرب

نظام SaaS متكامل بالعربية (RTL) لإدارة مكاتب المحاماة: الملفات والقضايا، الجلسات، الموكلون، الفواتير مع TVA والتفقيط، المصاريف القضائية، المستندات، المهام، الفريق والصلاحيات — مع تعدد مكاتب (multi-tenant) وخطط اشتراك.

## التشغيل (3 خطوات)

المتطلبات: [Node.js 20+](https://nodejs.org)

```bash
npm install        # تثبيت الاعتمادات
npm run db:push    # إنشاء قاعدة البيانات
npm run db:seed    # بيانات تجريبية جاهزة (اختياري)
npm run dev        # التشغيل على http://localhost:3000
```

أو ببساطة على ويندوز: **انقر مرتين على `start.bat`**.

## البنية التقنية

- **Next.js 15** (App Router) + TypeScript — واجهة وخلفية في مشروع واحد
- **Prisma + SQLite** — قاعدة بيانات جاهزة فوراً (قابلة للتحويل إلى PostgreSQL بتغيير سطر واحد)
- **Tailwind CSS 4** — تصميم عربي RTL أصلي بخطي Cairo وTajawal
- **مصادقة JWT** عبر cookies آمنة (httpOnly) + bcryptjs
- **multi-tenant**: كل مكتب له مساحة معزولة تماماً (كل استعلام مرشح بـ tenantId)

## خارطة الطريق (المراحل القادمة)

1. **النشر السحابي**: Vercel + PostgreSQL (Neon/Supabase) + S3 للملفات — المخطط متوافق
2. **الدفع الإلكتروني**: ربط CMI أو Payzone أو Stripe لتحصيل الاشتراكات تلقائياً
3. **إشعارات WhatsApp/SMS**: تنبيه الجلسات عبر WhatsApp Cloud API قبل X أيام (الإعداد موجود في الإعدادات)
4. **توليد PDF متقدم**: قوالب مذكرات ومقالات دعوى قابلة للتخصيص
5. **بوابة الموكل**: رابط خارجي يعرض حالة الملف وفواتيره
6. **تصدير Excel** ونسخ احتياطي تلقائي

## ملاحظات

- `.env` يحوي `AUTH_SECRET` — **غيّره قبل النشر**
- بيانات seed كاملة داخل `prisma/seed.ts` — عدّلها بحرية
- تصميم وهوية «قانوني» أصليان وليسان منسوخان من أي منتج قائم
